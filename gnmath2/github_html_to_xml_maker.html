How to use the result with jsDelivr
1. ConvertLoad your GitHub HTML URL, then click Convert to XML.
2. UploadUpload the downloaded .xml beside the original HTML and its JS/CSS/assets.
3. OpenUse the matching jsDelivr URL ending in /path/to/index.xml.
Important: Keep the XML in the same folder as the original HTML unless you also update relative asset paths. The tool preserves the original paths. This follows the repository's XML approach; it does not create the separate SVG wrapper.
Reference pattern: XHTML namespace + CDATA-wrapped CSS/scripts + dynamic import of the original external module.
